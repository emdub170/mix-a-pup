# Mix-a-Pup

A puppy-mixing game. Cross breeds to fill the Pupdex, train your pups, and send them to dog shows.

It is a static web app with no build step: `index.html` holds the whole game, `sw.js` makes it work offline, and `manifest.webmanifest` plus the icons let a phone install it to the home screen.

## Play it

- **On this computer:** open `index.html` in a browser.
- **On a phone:** host this folder on GitHub Pages, open the page, then use the browser's "Add to Home Screen".

## Updating

Push a change to the repository. The app shows the new version the second time it is opened after the push.

## Saves

The kennel is stored in the browser it is played in. To move it, open Settings, tap "Copy my save code", and paste the code into Settings on the other device.
